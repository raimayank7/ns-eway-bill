ମାଗଣା ଇ-ୱେ ବିଲ୍ JSON ଜେନେରେଟର୍ (ବଲ୍କ ଓ Part B)

ଇ-ୱେ ବିଲ୍ ପୋର୍ଟାଲର ବଲ୍କ ଅପଲୋଡ୍ ଯାହା ମାନେ ସେହି ଫାଇଲ୍ ବନାନ୍ତୁ: ଏଠାରେ ଟାଇପ୍ କରିଥିବା ଇନଭଏସ୍‌ରୁ, କିମ୍ବା ଅନେକ ଇନଭଏସ୍ ଓ ଚାଲାଣର Excel ସିଟ୍‌ରୁ। କେବଳ Part A ବନାଇବାକୁ ଗାଡ଼ି ଖାଲି ଛାଡ଼ନ୍ତୁ, ଗାଡ଼ି ଠିକ୍ ହେଲେ Part B ଗାଡ଼ି ଫାଇଲ୍ ବନାନ୍ତୁ। ଫାଇଲ୍ ଆପଣ ନିଜ ଲଗଇନ୍‌ରେ ଅପଲୋଡ୍ କରନ୍ତି; ଆମକୁ କିଛି ପଠାଯାଏ ନାହିଁ। ଅନେକ ପଠାଣ ଅଛି? ତଳେ Excel ଅପଲୋଡ୍ ବ୍ୟବହାର କରନ୍ତୁ।

Excel ରୁ ଥରକେ ଅନେକ ଇ-ୱେ ବିଲ୍, ଓ Part B ପରେ

ଦିନକୁ ଅନେକ ପଠାଣ କରନ୍ତି, ବା ଜବ୍ ୱାର୍କ ପାଇଁ ଚାଲାଣ କାଟନ୍ତି? ଗୋଟିଏ Excel ସିଟ୍ ଭରି ସବୁ ଇ-ୱେ ବିଲ୍ ପାଇଁ ଗୋଟିଏ ଫାଇଲ୍ ବନାନ୍ତୁ। ଗାଡ଼ି ଏପର୍ଯ୍ୟନ୍ତ ଠିକ୍ ହୋଇନାହିଁ? ଏବେ Part A ବନାନ୍ତୁ, ଗାଡ଼ି ଠିକ୍ ହେଲେ ଏଠାରେ ହିଁ ଗାଡ଼ି ଫାଇଲ୍ (Part B) ବନାନ୍ତୁ।

ଏଠାରେ ଇନଭଏସ୍ କିପରି ବନାଇବେ

  1. ଆପଣଙ୍କ ବିଜନେସ୍ ବିବରଣୀ ଥରେ ମାତ୍ର ଲେଖନ୍ତୁ। GSTIN, ଠିକଣା, ସହର / ଗାଁ, ପିନ୍ କୋଡ୍ ଓ ରାଜ୍ୟ। ସେଭ୍ ହୋଇଥିବା ବିଜନେସ୍ ଟାଇପ୍ କଲାବେଳେ ଦେଖାଯାଏ।
  2. କ୍ରେତା ଓ ମାଲ ଯୋଡନ୍ତୁ। କ୍ରେତାର GSTIN (ରେଜିଷ୍ଟର୍ ହୋଇନଥିଲେ ଖାଲି), ସହର ଓ ପିନ୍, ପ୍ରତ୍ୟେକ ଆଇଟମ୍ ତାର HSN କୋଡ୍ (4, 6 ବା 8 ଅଙ୍କ), ପରିମାଣ ଓ ମୂଲ୍ୟ ସହ।
  3. “ଇ-ଇନଭଏସ୍ ଓ ଇ-ୱେ ବିଲ୍” ଖୋଲନ୍ତୁ, ତା’ପରେ “ଟ୍ରାନ୍ସପୋର୍ଟ ବିବରଣୀ (ଇ-ୱେ ବିଲ୍ ପାଇଁ)”। ମାଲ ପଠାଇବାର କାରଣ, ଦୂରତା (0 = ପୋର୍ଟାଲ୍ ପିନ୍ କୋଡ୍‌ରୁ ବାହାର କରେ), ଏବଂ ଗାଡ଼ି ନମ୍ବର ବା ଟ୍ରାନ୍ସପୋର୍ଟରର ID।
  4. “ଇ-ୱେ ବିଲ୍ ଫାଇଲ୍ ଡାଉନଲୋଡ୍” ଦବାନ୍ତୁ। କିଛି ଅଭାବ ଥିଲେ କ’ଣ ଠିକ୍ କରିବେ ତାହାର ତାଲିକା ଦେଖାଯାଏ। ନହେଲେ Downloads ରେ .json ଫାଇଲ୍ ସେଭ୍ ହୁଏ।
  5. ପୋର୍ଟାଲରେ ଅପଲୋଡ୍ କରନ୍ତୁ। ewaybillgst.gov.in ରେ ସାଇନ୍ ଇନ୍ କରନ୍ତୁ (ରେଜିଷ୍ଟର୍ ମୋବାଇଲରେ OTP), e-Waybill › Generate Bulk ଖୋଲନ୍ତୁ, ଫାଇଲ୍ ବାଛନ୍ତୁ ଓ Generate ଦବାନ୍ତୁ।
  6. ଇ-ୱେ ବିଲ୍ ନମ୍ବର ସହ ଇନଭଏସ୍ ପ୍ରିଣ୍ଟ କରନ୍ତୁ। ପୋର୍ଟାଲର ଫଳାଫଳ ଏଠାରେ ଲୋଡ୍ କରନ୍ତୁ (ବା ନମ୍ବର ଲେଖନ୍ତୁ), “ସେଭ୍ କରନ୍ତୁ” ଦବାନ୍ତୁ, ତା’ପରେ “ପ୍ରିଣ୍ଟ / PDF”। ଇନଭଏସ୍‌ରେ ଇ-ୱେ ବିଲ୍ ନମ୍ବର ଓ ଏହାର ବୈଧତା ଦେଖାଯାଏ।

ଏହା ଆପଣଙ୍କ ପାଇଁ କ’ଣ କରେ

  • ଅପଲୋଡ୍ ପୂର୍ବରୁ ଯାଞ୍ଚ: GSTIN ର ଚେକ୍ ଡିଜିଟ୍, ପିନ୍ ଓ ସହର, HSN ର ଲମ୍ବ, ଗାଡ଼ି ନମ୍ବରର ଢାଞ୍ଚା (ଭାରତ ସିରିଜ୍ ସହ), 4,000 କିମି ପର୍ଯ୍ୟନ୍ତ ଦୂରତା, 180 ଦିନରୁ ପୁରୁଣା ଡକ୍ୟୁମେଣ୍ଟ।
  • ଅନେକ ଥରକେ: ଇନଭଏସ୍, ବିଲ୍ ଅଫ୍ ସପ୍ଲାଇ ଓ ଡେଲିଭରୀ ଚାଲାଣ (ଜବ୍ ୱାର୍କ, ନିଜ ବ୍ୟବହାର, ପ୍ରଦର୍ଶନୀ, ଲାଇନ୍ ସେଲ୍ସ, SKD/CKD) ଗୋଟିଏ Excel ସିଟ୍‌ରୁ, କେଉଁ ଡକ୍ୟୁମେଣ୍ଟ କେଉଁ କାରଣରେ ଚଳେ ସେ ବିଷୟରେ ପୋର୍ଟାଲର ନିଜ ନିୟମ ସହ।
  • ଏବେ Part A, ପରେ Part B: କେବଳ Part A ବନାଇବାକୁ ଗାଡ଼ି ଖାଲି ଛାଡ଼ନ୍ତୁ, ତା’ପରେ ଅନେକ ଇ-ୱେ ବିଲ୍ ପାଇଁ ଥରକେ ଗାଡ଼ି ଅପଡେଟ୍ ଫାଇଲ୍ ଡାଉନଲୋଡ୍ କରନ୍ତୁ।
  • Bill to - ship to: କ୍ରେତାର ଠିକଣାଠାରୁ ଅଲଗା ଠିକଣାକୁ ଯାଉଥିବା ମାଲ ପୋର୍ଟାଲ୍ ଚାହୁଁଥିବା ଢଙ୍ଗରେ ପଠାଯାଏ।
  • ରାଜ୍ୟର ସୀମା ଜାଣେ: ଆପଣଙ୍କ ରାଜ୍ୟ ଭିତରର ପଠାଣ ସେହି ରାଜ୍ୟର ନିଜ ସୀମାଠାରୁ କମ୍ ହେଲେ ଜଣାଏ।
  • ଆପଣଙ୍କ ଭାଷାରେ: ସ୍କ୍ରିନ୍‌ରେ 24 ଭାଷା; ପୋର୍ଟାଲକୁ ଦରକାର ବୋଲି ଫାଇଲ୍ ଓ ଇନଭଏସ୍ ଇଂରାଜୀରେ ରହେ।

ଆପଣଙ୍କ ଡାଟା ଆପଣଙ୍କ ପାଖରେ ରହେ

ଆପଣ ଯାହା ଟାଇପ୍ କରନ୍ତି ସବୁ ଏହି ଡିଭାଇସ୍‌ର ଏହି ବ୍ରାଉଜର୍‌ରେ ରହେ। ଆକାଉଣ୍ଟ ନାହିଁ ଏବଂ ଆମକୁ କିଛି ଅପଲୋଡ୍ ହୁଏ ନାହିଁ। ଆପଣଙ୍କ ବିଜନେସ୍, ଗ୍ରାହକ, ସପ୍ଲାୟର୍ ଓ ଆଇଟମ୍ my.niveshsahayak.in ମାଧ୍ୟମରେ Nivesh Sahayak ର ଅନ୍ୟ ଡକ୍ୟୁମେଣ୍ଟ ଟୁଲ୍ ସହ ଶେୟାର୍ ହୁଏ, ତେଣୁ ଇନଭଏସ୍ ବା କୋଟେସନ ବନାଇବାବେଳେ ସେଭ୍ କରିଥିବା ବିବରଣୀ ଏଠାରେ ଆଗରୁ ସୁଝାବ ଭାବେ ମିଳେ।

ବ୍ୟାକଅପ୍ ରଖନ୍ତୁ। ବ୍ରାଉଜର୍‌ର ଡାଟା ମାଜି ଦିଆଗଲେ ତାହାରେ ସେଭ୍ କରିଥିବା କାମ ଚାଲିଯାଏ। ପୃଷ୍ଠାର ଉପରେ ଥିବା ମୋ ଡାଟା ଖୋଲନ୍ତୁ ଓ ବେଳେବେଳେ ବ୍ୟାକଅପ୍ ଫାଇଲ୍ ସେଭ୍ କରନ୍ତୁ ଦବାନ୍ତୁ। ଗୋଟିଏ ଫାଇଲ୍‌ରେ ସବୁ ଡକ୍ୟୁମେଣ୍ଟ, ଗ୍ରାହକ ଓ ଆଇଟମ୍ ଥାଏ, ଏବଂ ତାହା ଅନ୍ୟ ଯେକୌଣସି କମ୍ପ୍ୟୁଟର ବା ଫୋନ୍‌ରେ ଫେରାଇ ଆଣିହୁଏ।

ଗାଇଡ୍

ଇ-ୱେ ବିଲ୍ କେବେ ଦରକାର?₹50,000 ନିୟମ, ରାଜ୍ୟ ସୀମା, ଜବ୍ ୱାର୍କ। ବୈଧତା ଓ Part Bକେତେ ଦିନ ଚଳେ, ଗାଡ଼ି ବଦଳ, ଅବଧି ବଢ଼ାଇବା। Excel ରୁ ଅନେକ ଇ-ୱେ ବିଲ୍ଟେମ୍ପଲେଟ୍, କାରଣ ଓ ଡକ୍ୟୁମେଣ୍ଟ ପ୍ରକାର, ଅପଲୋଡ୍। ଇ-ୱେ ବିଲ୍ JSON ଫର୍ମାଟବଲ୍କ ଫାଇଲ୍‌ର ଫିଲ୍ଡ ଓ କୋଡ୍।

ଲୋକେ ପଚାରୁଥିବା ପ୍ରଶ୍ନ

ଏହା କ’ଣ ସରକାରୀ ଇ-ୱେ ବିଲ୍ ପୋର୍ଟାଲ୍?

ନା। Nivesh Sahayak NIC ବା GSTN ର ଅଂଶ ନୁହେଁ। ଏହା ପୋର୍ଟାଲର ପ୍ରକାଶିତ ବଲ୍କ ଫର୍ମାଟରେ ଆପଣଙ୍କ ବ୍ରାଉଜର୍‌ରେ ହିଁ ଫାଇଲ୍ ବନାଏ; ଆପଣ ନିଜ ଲଗଇନ୍‌ରେ ewaybillgst.gov.in ରେ ତାହା ଅପଲୋଡ୍ କରନ୍ତି ଏବଂ ପୋର୍ଟାଲ୍ ହିଁ ଇ-ୱେ ବିଲ୍ ବନାଏ।

ଗାଡ଼ି ନମ୍ବର ବିନା ଇ-ୱେ ବିଲ୍ ବନାଇ ହେବ କି?

ହଁ। ଗାଡ଼ି ଓ ମାଧ୍ୟମ ଖାଲି ଛାଡ଼ନ୍ତୁ, କେବଳ Part A ହେବ (ସଡ଼କ ପଥରେ ଟ୍ରାନ୍ସପୋର୍ଟରର ID ଦେଲେ ଟ୍ରାନ୍ସପୋର୍ଟର ଗାଡ଼ି ଯୋଡ଼ିପାରେ)। Part B ଯୋଡ଼ିବା ଯାଏ ଏହାର ବୈଧତା ନଥାଏ; Part B ଗାଡ଼ି ଫାଇଲ୍ Excel ଅଂଶର ଷ୍ଟେପ୍ 4 ରେ ବନାନ୍ତୁ।

ଡେଲିଭରୀ ଚାଲାଣ ପାଇଁ ଇ-ୱେ ବିଲ୍ ବନାଇ ହେବ କି?

ହଁ, Excel ସିଟ୍‌ରେ: Document Type CHL ସହ Sub Supply Type Job Work, For Own Use, Exhibition or Fairs, Line Sales, SKD/CKD/Lots, Recipient Not Known ବା Others। ଚାଲାଣରେ ଟ୍ୟାକ୍ସ ହାର 0 ହେବା ଦରକାର।

ଠିକ୍ ₹50,000 ପାଇଁ ଇ-ୱେ ବିଲ୍ ଦରକାର କି?

ନା। ମୂଲ୍ୟ (GST ସହ) ₹50,000 ରୁ ଅଧିକ ହେଲେ ଦରକାର। କିଛି ରାଜ୍ୟ ଭିତରେ ସୀମା ଅଧିକ, ଅନେକରେ ₹1 ଲକ୍ଷ।

ମୋତେ ଇ-ଇନଭଏସ୍ ଦେବାକୁ ପଡ଼େ। ଏହା ବ୍ୟବହାର କରିହେବ କି?
