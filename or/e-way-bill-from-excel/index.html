Excel ରୁ ଥରକେ ଅନେକ ଇ-ୱେ ବିଲ୍

ପୋର୍ଟାଲର ବଲ୍କ ଜେନେରେସନ୍ ଅନେକ ଇ-ୱେ ବିଲ୍ ଥିବା ଗୋଟିଏ JSON ଫାଇଲ୍ ନିଏ। ଆମ Excel ଟେମ୍ପଲେଟ୍ ଭରନ୍ତୁ, ପ୍ରତି ଆଇଟମ୍‌ରେ ଗୋଟିଏ ଧାଡ଼ି, ଏବଂ ମେକର୍ ତାହାରୁ ସେହି ଫାଇଲ୍ ବନାଏ; ଆଗରୁ ପ୍ରତ୍ୟେକ ଇ-ୱେ ବିଲ୍‌କୁ ପୋର୍ଟାଲର ନିଜ ନିୟମ ଅନୁସାରେ ଯାଞ୍ଚ କରେ।

ଷ୍ଟେପ୍ ଷ୍ଟେପ୍

  1. Excel ଅଂଶର ଷ୍ଟେପ୍ 1 ରେ ଆପଣଙ୍କ ବିଜନେସ୍ ବାଛନ୍ତୁ (ସେଭ୍ ହୋଇଥିବା ବିଜନେସ୍ ମଧ୍ୟରୁ; ଦରକାର ହେଲେ ମୋ ଡାଟା ରେ ଗୋଟିଏ ଯୋଡନ୍ତୁ)।
  2. Excel ଟେମ୍ପଲେଟ୍ ଡାଉନଲୋଡ୍ କରନ୍ତୁ। How to fill ସିଟ୍‌ରେ ପ୍ରତ୍ୟେକ ସ୍ତମ୍ଭ ବୁଝାଯାଇଛି।
  3. ପ୍ରତି ଆଇଟମ୍‌ରେ ଗୋଟିଏ ଧାଡ଼ି। ଏକା Document No ଥିବା ଧାଡ଼ିଗୁଡ଼ିକ ମିଶି ଗୋଟିଏ ଇ-ୱେ ବିଲ୍ ହୁଏ; କ୍ରେତା ଓ ଟ୍ରାନ୍ସପୋର୍ଟ ବିବରଣୀ ଏହାର ପ୍ରଥମ ଧାଡ଼ିରୁ ନିଆଯାଏ।
  4. ଭରିଥିବା ଫାଇଲ୍ ବାଛନ୍ତୁ (.xlsx ବା CSV UTF-8)। ତାଲିକାରେ ଦେଖାଯାଉଥିବା ଧାଡ଼ିଗୁଡ଼ିକ ଠିକ୍ କରନ୍ତୁ, ସେଭ୍ କରନ୍ତୁ ଓ ପୁଣି ବାଛନ୍ତୁ।
  5. ଇ-ୱେ ବିଲ୍ ଫାଇଲ୍ ଡାଉନଲୋଡ୍ କରନ୍ତୁ ଓ ewaybillgst.gov.in › e-Waybill › Generate Bulk › Choose file › Generate ରେ ଅପଲୋଡ୍ କରନ୍ତୁ।
  6. ପୋର୍ଟାଲ୍ ଇ-ୱେ ବିଲ୍ ନମ୍ବରଗୁଡ଼ିକର ତାଲିକା ଦିଏ। ସେଠାରେ Export to Excel ଦବାନ୍ତୁ ଓ ସେହି ଫାଇଲ୍ ଏଠାରେ ଷ୍ଟେପ୍ 3 ରେ ବାଛନ୍ତୁ: ନମ୍ବରଗୁଡ଼ିକ ଆପଣଙ୍କ ସେଭ୍ ହୋଇଥିବା ଇନଭଏସ୍ ଓ Part B ଟେବୁଲ୍‌ରେ ଯାଏ।
  7. ଗାଡ଼ି ଏପର୍ଯ୍ୟନ୍ତ ନାହିଁ? Part B ଟେବୁଲ୍ ପରେ ଭରନ୍ତୁ ଓ ଗାଡ଼ି ଫାଇଲ୍ e-Waybill › Update Vehicle Bulk ରେ ଅପଲୋଡ୍ କରନ୍ତୁ।

କେଉଁ ଡକ୍ୟୁମେଣ୍ଟ କେଉଁ କାରଣ ପାଇଁ

ଗୋଟିଏ ଉଦାହରଣ

ଲୁଧିଆନାର ଏକ ଗାର୍ମେଣ୍ଟ ୟୁନିଟ୍ ଚାଲାଣ DC/26-27/045 ରେ ₹38,000 ମୂଲ୍ୟର କଟା କପଡ଼ା ପାନିପତ୍ (ହରିୟାଣା) ର ଜବ୍ ୱାର୍କରଙ୍କ ପାଖକୁ ପଠାଏ। ଅନ୍ୟ ରାଜ୍ୟରେ ଜବ୍ ୱାର୍କ ପାଇଁ ଯେକୌଣସି ମୂଲ୍ୟରେ ଇ-ୱେ ବିଲ୍ ଦରକାର। ଧାଡ଼ି: Document No DC/26-27/045, Document Type CHL, Sub Supply Type Job Work, GST % 0, Transport Mode Road, Vehicle No PB10AB1234, Distance 0।

ଆଗେ ଛୋଟ ଫାଇଲ୍ ପରୀକ୍ଷା କରନ୍ତୁ। ପୋର୍ଟାଲ୍ କୌଣସି ଧାଡ଼ି ଫେରାଇ ଦେଲେ ଫିଲ୍ଡର ନାମ କହେ: Excel ରେ ଠିକ୍ କରନ୍ତୁ ଓ ଫାଇଲ୍ ପୁଣି ବନାନ୍ତୁ।
