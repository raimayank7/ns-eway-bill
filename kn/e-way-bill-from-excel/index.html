ಇ-ವೇ ಬಿಲ್ › Excel ನಿಂದ ಇ-ವೇ ಬಿಲ್‌ಗಳು

Excel ನಿಂದ ಒಂದೇ ಬಾರಿ ಹಲವು ಇ-ವೇ ಬಿಲ್‌ಗಳು

ಪೋರ್ಟಲ್‌ನ ಬಲ್ಕ್ ಜನರೇಷನ್ ಹಲವು ಇ-ವೇ ಬಿಲ್‌ಗಳಿರುವ ಒಂದೇ JSON ಫೈಲ್ ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ. ನಮ್ಮ Excel ಟೆಂಪ್ಲೇಟ್ ತುಂಬಿ, ಒಂದು ಐಟಂಗೆ ಒಂದು ಸಾಲು; ಮೇಕರ್ ಅದನ್ನು ಆ ಫೈಲ್ ಆಗಿ ಮಾಡುತ್ತದೆ, ಅದಕ್ಕೂ ಮೊದಲು ಪ್ರತಿ ಇ-ವೇ ಬಿಲ್ ಅನ್ನು ಪೋರ್ಟಲ್‌ನ ಸ್ವಂತ ನಿಯಮಗಳ ಪ್ರಕಾರ ಪರಿಶೀಲಿಸುತ್ತದೆ.

ಹಂತ ಹಂತವಾಗಿ

  1. ನಿಮ್ಮ ಬಿಸಿನೆಸ್ ಆಯ್ಕೆಮಾಡಿ (Excel ಭಾಗದ 1ನೇ ಹಂತದಲ್ಲಿ; ನೀವು ಸೇವ್ ಮಾಡಿದ ಬಿಸಿನೆಸ್‌ಗಳಿಂದ; ಬೇಕಾದರೆ ನನ್ನ ಡೇಟಾದಲ್ಲಿ ಒಂದನ್ನು ಸೇರಿಸಿ).
  2. Excel ಟೆಂಪ್ಲೇಟ್ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ. ಪ್ರತಿ ಕಾಲಮ್ ಅನ್ನು How to fill ಶೀಟ್ ವಿವರಿಸುತ್ತದೆ.
  3. ಒಂದು ಐಟಂಗೆ ಒಂದು ಸಾಲು. ಒಂದೇ Document No ಇರುವ ಸಾಲುಗಳು ಸೇರಿ ಒಂದು ಇ-ವೇ ಬಿಲ್ ಆಗುತ್ತವೆ; ಖರೀದಿದಾರ ಮತ್ತು ಸಾರಿಗೆ ವಿವರಗಳನ್ನು ಅದರ ಮೊದಲ ಸಾಲಿನಿಂದ ಓದುತ್ತದೆ.
  4. ತುಂಬಿದ ಫೈಲ್ ಆಯ್ಕೆಮಾಡಿ (.xlsx ಅಥವಾ CSV UTF-8). ಪಟ್ಟಿ ತೋರಿಸುವ ಸಾಲುಗಳನ್ನು ಸರಿಪಡಿಸಿ, ಸೇವ್ ಮಾಡಿ, ಮತ್ತೆ ಆಯ್ಕೆಮಾಡಿ.
  5. ಇ-ವೇ ಬಿಲ್ ಫೈಲ್ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ewaybillgst.gov.in › e-Waybill › Generate Bulk › Choose file › Generate ಮೂಲಕ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ.
  6. ಪೋರ್ಟಲ್ ಇ-ವೇ ಬಿಲ್ ಸಂಖ್ಯೆಗಳನ್ನು ತೋರಿಸುತ್ತದೆ. ಅಲ್ಲಿ Export to Excel ಒತ್ತಿ, ಆ ಫೈಲ್ ಅನ್ನು ಇಲ್ಲಿ 3ನೇ ಹಂತದಲ್ಲಿ ಆಯ್ಕೆಮಾಡಿ: ಸಂಖ್ಯೆಗಳು ನೀವು ಸೇವ್ ಮಾಡಿದ ಇನ್‌ವಾಯ್ಸ್‌ಗಳಿಗೆ ಮತ್ತು Part B ಕೋಷ್ಟಕಕ್ಕೆ ಸೇರುತ್ತವೆ.
  7. ಇನ್ನೂ ವಾಹನ ಇಲ್ಲವೇ? Part B ಕೋಷ್ಟಕವನ್ನು ನಂತರ ತುಂಬಿ, ವಾಹನ ಫೈಲ್ ಅನ್ನು e-Waybill › Update Vehicle Bulk ಮೂಲಕ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ.

ಯಾವ ಕಾರಣಕ್ಕೆ ಯಾವ ಡಾಕ್ಯುಮೆಂಟ್

ಲೆಕ್ಕ ಸಹಿತ ಉದಾಹರಣೆ

ಲೂಧಿಯಾನಾದ ಒಂದು ಗಾರ್ಮೆಂಟ್ ಯೂನಿಟ್ ಕತ್ತರಿಸಿದ ಬಟ್ಟೆಯನ್ನು ಪಾನಿಪತ್ (ಹರಿಯಾಣ) ನಲ್ಲಿರುವ ಜಾಬ್ ವರ್ಕರ್‌ಗೆ ₹38,000 ಮೌಲ್ಯದ ಚಲನ್ DC/26-27/045 ಮೇಲೆ ಕಳುಹಿಸುತ್ತಿದೆ. ಬೇರೆ ರಾಜ್ಯಕ್ಕೆ ಜಾಬ್ ವರ್ಕ್ ಆದರೆ ಯಾವುದೇ ಮೌಲ್ಯಕ್ಕೂ ಇ-ವೇ ಬಿಲ್ ಬೇಕು. ಸಾಲು: Document No DC/26-27/045, Document Type CHL, Sub Supply Type Job Work, GST % 0, Transport Mode Road, Vehicle No PB10AB1234, Distance 0.

ಮೊದಲು ಸಣ್ಣ ಫೈಲ್‌ನಿಂದ ಪ್ರಯತ್ನಿಸಿ. ಪೋರ್ಟಲ್ ಒಂದು ಸಾಲನ್ನು ತಿರಸ್ಕರಿಸಿದರೆ ಅದು ಯಾವ ಫೀಲ್ಡ್ ಎಂದು ಹೇಳುತ್ತದೆ: Excel ನಲ್ಲಿ ಸರಿಪಡಿಸಿ ಮತ್ತೆ ಫೈಲ್ ಮಾಡಿ.
ನಿಮ್ಮ ಇ-ವೇ ಬಿಲ್ ಫೈಲ್ ಅನ್ನು ಈಗಲೇ ಮಾಡಿ: ಒಂದು ಇನ್‌ವಾಯ್ಸ್ ಅಥವಾ ಇಡೀ ಶೀಟ್.ಮೇಕರ್ ತೆರೆಯಿರಿ
