Excel-ৰ পৰা এবাৰতে বহুতো ই-ৱে বিল

পৰ্টেলৰ বাল্ক জেনেৰেচনে বহুতো ই-ৱে বিলসহ এটা JSON ফাইল লয়। আমাৰ Excel টেমপ্লেট ভৰাওক, প্ৰতিটো আইটেমৰ বাবে এটা শাৰী, আৰু মেকাৰে সেইটো সেই ফাইললৈ ৰূপান্তৰ কৰি দিয়ে, আগতে প্ৰতিটো ই-ৱে বিল পৰ্টেলৰ নিজৰ নিয়মেৰে পৰীক্ষা কৰি।

ধাপে ধাপে

  1. Excel অংশৰ ধাপ 1 ত আপোনাৰ ব্যৱসায় বাছক (আপোনাৰ ছেভ কৰা ব্যৱসায়ৰ ভিতৰৰ পৰা; লাগিলে মোৰ ডেটা ত এটা যোগ কৰক)।
  2. Excel টেমপ্লেট ডাউনলোড কৰক। How to fill শ্বীটত প্ৰতিটো কলাম বুজোৱা আছে।
  3. প্ৰতিটো আইটেমৰ বাবে এটা শাৰী। একে Document No ৰ শাৰীবোৰে মিলি এটা ই-ৱে বিল হয়; ক্ৰেতা আৰু ট্ৰান্সপৰ্টৰ তথ্য তাৰ প্ৰথম শাৰীৰ পৰা পঢ়া হয়।
  4. ভৰোৱা ফাইল বাছক (.xlsx বা CSV UTF-8)। তালিকাত দেখুওৱা শাৰীবোৰ ঠিক কৰক, ছেভ কৰক, আকৌ বাছক।
  5. ই-ৱে বিল ফাইল ডাউনলোড কৰক আৰু ewaybillgst.gov.in › e-Waybill › Generate Bulk › Choose file › Generate ত আপলোড কৰক।
  6. পৰ্টেলে ই-ৱে বিল নম্বৰবোৰ দেখুৱায়। তাতে Export to Excel টিপক আৰু সেই ফাইল ইয়াত ধাপ 3 ত বাছক: নম্বৰবোৰ আপোনাৰ ছেভ কৰা ইনভইচত আৰু Part B তালিকাত যায়।
  7. এতিয়াও গাড়ী নাই নেকি? Part B তালিকা পাছত ভৰাওক আৰু গাড়ীৰ ফাইল e-Waybill › Update Vehicle Bulk ত আপলোড কৰক।

কোনো কাৰণত কোন ডকুমেণ্ট

বাহিৰলৈ যোৱা সামগ্ৰীৰ বাবে পৰ্টেলে কেৱল এই যোৰবোৰ গ্ৰহণ কৰে (NIC বাল্ক ভেলিডেচন):

SupplyINV টেক্স ইনভইচ, BIL বিল অৱ ছাপ্লাইক্ৰেতা (GSTIN সহ বা পঞ্জীয়ন নথকা)

For Own Use, Exhibition or Fairs, Line SalesCHLনিজে (নিজৰ GSTIN)

বিল অৱ ছাপ্লাই, ডেলিভাৰী চালান বা “others” ৰ লগত প্ৰতিটো আইটেমত টেক্স ৰেট 0 হ’ব লাগিব। “own use”, প্ৰদৰ্শনী, লাইন ছেলছ আৰু “recipient not known” ত মেকাৰে আপোনাৰ নিজৰ GSTIN ক প্ৰাপক হিচাপে বহুৱাই দিয়ে।

এটা সম্পূৰ্ণ উদাহৰণ

লুধিয়ানাৰ এটা গাৰ্মেণ্ট ইউনিটে চালান DC/26-27/045 ত ₹38,000 ৰ কটা কাপোৰ পানিপথৰ (হৰিয়ানা) এজন জব ৱৰ্কাৰলৈ পঠাইছে। আন ৰাজ্যত জব ৱৰ্কৰ বাবে যিকোনো মূল্যত ই-ৱে বিল লাগে। শাৰী: Document No DC/26-27/045, Document Type CHL, Sub Supply Type Job Work, GST % 0, Transport Mode Road, Vehicle No PB10AB1234, Distance 0।

আগতে এটা সৰু ফাইল চেষ্টা কৰক। পৰ্টেলে কোনো শাৰী নাকচ কৰিলে ফিল্ডৰ নাম কয়: Excel ত ঠিক কৰি ফাইল আকৌ বনাওক।
