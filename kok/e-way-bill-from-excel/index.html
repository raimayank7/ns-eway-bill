Excel वयल्यान एकाच वेळार जायतीं ई-वे बिलां

पोर्टलाचें बल्क जनरेशन जायत्या ई-वे बिलांची एक JSON फायल घेता. आमचें Excel टेम्प्लेट भरात, दरेक आयटमाक एक वळ, आनी मेकर ताची ती फायल करता; तत्पूर्वी दरेक ई-वे बिल पोर्टलाच्याच नेमांविरोधी तपासता.

पावला पावलान

  1. Excel भागाच्या पायरी 1 त तुमचो बिझनेस वेंचून काढात (तुमच्या सेव केल्ल्या बिझनेसां मदल्यान; गरज आसल्यार म्हजो डेटा त एक जोडात).
  2. Excel टेम्प्लेट डाउनलोड करात. How to fill शीट दरेक कॉलम सांगता.
  3. दरेक आयटमाक एक वळ. एकूच Document No आशिल्ल्या वळी मेळून एक ई-वे बिल जाता; खरेदीदार आनी ट्रान्सपोर्टाची म्हायती ताच्या पयल्या वळी वयल्यान वाचतात.
  4. भरिल्ली फायल वेंचून काढात (.xlsx वा CSV UTF-8). यादी दाखयता त्यो वळी नीट करात, सेव करात आनी फायल परत वेंचून काढात.
  5. ई-वे बिल फायल डाउनलोड करात आनी ewaybillgst.gov.in › e-Waybill › Generate Bulk › Choose file › Generate चेर अपलोड करात.
  6. पोर्टल ई-वे बिल नंबरांची यादी दिता. थंय Export to Excel दाबात आनी हांगा पायरी 3 त ती फायल वेंचून काढात: नंबर तुमच्या सेव केल्ल्या इनवॉयसांचेर आनी Part B तक्त्यांत वतात.
  7. अजून गाडी ना? Part B तक्तो उपरांत भरात आनी गाडयेची फायल e-Waybill › Update Vehicle Bulk खाला अपलोड करात.

भायर वतल्या मालाखातीर पोर्टल फकत ह्यो जोडयो घेता (NIC चे बल्क वॅलिडेशन):

बिल ऑफ सप्लाय, डिलिव्हरी चलन वा "others" आसल्यार दरेक आयटमाचेर टॅक्स रेट 0 जाय. "own use", प्रदर्शन, लायन सेल्स आनी "recipient not known" खातीर मेकर रिसिव्हर म्हणून तुमचोच GSTIN आपसूक घालता.

एक उदाहरण

लुधियाणांतलें एक गारमेंट युनिट कापिल्लें कापड पानिपताच्या (हरयाणा) जॉब वर्करा कडेन चलन DC/26-27/045 वयल्यान धाडटा, ₹38,000 चें. हेर राज्यांतल्या जॉब वर्काखातीर खंयचेय वॅल्यूचेर ई-वे बिल जाय. वळ: Document No DC/26-27/045, Document Type CHL, Sub Supply Type Job Work, GST % 0, Transport Mode Road, Vehicle No PB10AB1234, Distance 0.

आदीं ल्हान फायल करून पळयात. पोर्टलान खंयचीय वळ न्हयकारली जाल्यार तो फील्डाचें नांव सांगता: Excel त नीट करात आनी फायल परत करात.
