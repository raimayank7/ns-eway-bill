ઈ-વે બિલ › Excel માંથી ઈ-વે બિલ

Excel માંથી એકસાથે ઘણાં ઈ-વે બિલ

પોર્ટલનું બલ્ક જનરેશન ઘણાં ઈ-વે બિલવાળી એક JSON ફાઇલ લે છે. અમારું Excel ટેમ્પ્લેટ ભરો, દરેક આઇટમ માટે એક લાઇન, અને મેકર તેને તે ફાઇલમાં ફેરવે છે; તે પહેલાં દરેક ઈ-વે બિલ પોર્ટલના પોતાના નિયમો સામે તપાસાય છે.

સ્ટેપ બાય સ્ટેપ

  1. Excel વિભાગના સ્ટેપ 1 માં તમારો બિઝનેસ પસંદ કરો (સેવ કરેલા બિઝનેસમાંથી; જરૂર હોય તો મારો ડેટા માં એક ઉમેરો).
  2. Excel ટેમ્પ્લેટ ડાઉનલોડ કરો. How to fill શીટ દરેક કૉલમ સમજાવે છે.
  3. દરેક આઇટમ માટે એક લાઇન. એક જ Document No વાળી લાઇનો મળીને એક ઈ-વે બિલ બને છે; ખરીદદાર અને ટ્રાન્સપોર્ટની માહિતી તેની પહેલી લાઇનમાંથી વંચાય છે.
  4. ભરેલી ફાઇલ પસંદ કરો (.xlsx કે CSV UTF-8). યાદી જે લાઇનો બતાવે તે સુધારો, સેવ કરો અને ફરી પસંદ કરો.
  5. ઈ-વે બિલ ફાઇલ ડાઉનલોડ કરો અને ewaybillgst.gov.in › e-Waybill › Generate Bulk › Choose file › Generate પર અપલોડ કરો.
  6. પોર્ટલ ઈ-વે બિલ નંબરની યાદી આપે છે. ત્યાં Export to Excel દબાવો અને અહીં સ્ટેપ 3 માં તે ફાઇલ પસંદ કરો: નંબર તમારાં સેવ કરેલાં ઇન્વૉઇસ પર અને Part B ટેબલમાં આવી જાય છે.
  7. હજી ગાડી નથી? Part B ટેબલ પછીથી ભરો અને ગાડીની ફાઇલ e-Waybill › Update Vehicle Bulk હેઠળ અપલોડ કરો.

કયા કારણ માટે કયું ડોક્યુમેન્ટ

બહાર જતા માલ માટે પોર્ટલ ફક્ત આ જોડીઓ સ્વીકારે છે (NIC ના બલ્ક વેલિડેશન):

Sub Supply Type (કારણ)Document Typeકોને જાય છે
SupplyINV ટેક્સ ઇન્વૉઇસ, BIL બિલ ઑફ સપ્લાયખરીદદાર (GSTIN સાથે કે અનરજિસ્ટર્ડ)
ExportINV, BILઅનરજિસ્ટર્ડ (URP), ભારત બહાર
Job WorkCHL ડિલિવરી ચલણજોબ વર્કર
SKD/CKD/LotsINV, BIL, CHLખરીદદાર
For Own Use, Exhibition or Fairs, Line SalesCHLતમે પોતે (તમારો જ GSTIN)
Recipient Not KnownCHL, OTHતમે પોતે
Others (શું છે તે લખો)CHL, OTHતમે પોતે અથવા બીજી પાર્ટી

બિલ ઑફ સપ્લાય, ડિલિવરી ચલણ કે "others" સાથે દરેક આઇટમ પર ટેક્સ રેટ 0 હોવો જોઈએ. "own use", પ્રદર્શન, લાઇન સેલ્સ અને "recipient not known" માટે મેકર રિસીવર તરીકે તમારો પોતાનો GSTIN જાતે મૂકે છે.

ટ્રાન્સપોર્ટની કૉલમ

કૉલમશું ટાઇપ કરવું
Distance kmવધુમાં વધુ 4,000. 0 લખો તો પોર્ટલ PIN કોડ પરથી જાતે કાઢે છે.
Transport ModeRoad, Rail, Air કે Ship. ખાલી (અને ગાડી નહીં) = ફક્ત Part A.
Vehicle No, Vehicle Typeજેમ કે PB10AB1234; R સામાન્ય, O મોટા કદનો માલ
Transporter ID, Nameટ્રાન્સપોર્ટરનો GSTIN કે 15 અક્ષરનો TRANSIN. રોડથી જતું હોય તો આ અથવા ગાડી આપો.
Transport Doc No, DateLR, RR કે એરવે બિલ. રેલ અને હવાઈ માટે જોઈએ.
Ship To Address, City, PIN, State Codeમાલ ખરીદદારના સરનામા કરતાં બીજી જગ્યાએ જતો હોય ત્યારે જ; એક્સપોર્ટ માટે ભારતનું પોર્ટ.

એક ઉદાહરણ

લુધિયાણાનું એક ગારમેન્ટ યુનિટ કાપેલું કાપડ પાણીપત (હરિયાણા) ના જોબ વર્કરને ચલણ DC/26-27/045 પર મોકલે છે, ₹38,000 નું. બીજા રાજ્યમાં જોબ વર્ક માટે ગમે તેટલી વેલ્યુ પર ઈ-વે બિલ જોઈએ. લાઇન: Document No DC/26-27/045, Document Type CHL, Sub Supply Type Job Work, GST % 0, Transport Mode Road, Vehicle No PB10AB1234, Distance 0.

પહેલાં નાની ફાઇલ અજમાવો. પોર્ટલ કોઈ લાઇન નકારે તો તે ફીલ્ડનું નામ જણાવે છે: Excel માં સુધારો અને ફાઇલ ફરી બનાવો.
