Excel پیٚٹھٕ اکی ساعتہٕ واریاہ ای-وے بِل

پورٹلُک بلک جنریشن چھُ واریاہن ای-وے بِلن ہند اکھ JSON فایِل ہیوان۔ اَسہِ ہِنٛد Excel ٹیمپلیٹ بٔرِو، ہر آئٹمُک اکھ قطار؛ میکر چھُ یہِ تَتھ فایِلس منٛز تبدیل کران، تہٕ پؠٹھمس چھُ ہر ای-وے بِل پورٹلہٕ ہندین پانَن اصولن سٕتۍ جانچان۔

قدم بہ قدم

  1. Excel حصہٕ ہند قدم 1 منٛز پانُن بزنس ژارِو (سیو کرنہٕ آمتَن بزنسن منٛزہ؛ ضرورت آسنہٕ پیٚٹھ میون ڈیٹا منٛز اکھ ؤتھٲوِو)۔
  2. Excel ٹیمپلیٹ ڈاؤن لوڈ کٔرِو۔ ہر کالم چھُ How to fill شیٹس منٛز سمجھاونہٕ آمت۔
  3. ہر آئٹمُک اکھ قطار۔ اکی Document No والیٚن قطارن سٕتۍ بنان اکھ ای-وے بِل؛ خریدارُک تہٕ ٹرانسپورٹٕچ تفصیل چھ پتھمہِ قطارہٕ پیٚٹھٕ ہیوان۔
  4. بٔرتھ فایِل ژارِو (.xlsx یا CSV UTF-8)۔ فہرستس منٛز ظٲہر آمتۍ قطارہٕ ٹھیک کٔرِو، سیو کٔرِو، تہٕ دوبارہ ژارِو۔
  5. ای-وے بِل فایِل ڈاؤن لوڈ کٔرِو تہٕ ewaybillgst.gov.in › e-Waybill › Generate Bulk › Choose file › Generate پیٚٹھٕ اپ لوڈ کٔرِو۔
  6. پورٹل چھُ ای-وے بِل نمبرن ہند فہرست دوان۔ تتھ پیٚٹھ Export to Excel دبٲوِو تہٕ سۄ فایِل ییٹھ قدم 3 منٛز ژارِو: نمبر چھِ تُہٕنزن سیو کرنہٕ آمتن انوائسن تہٕ Part B ٹیبلس منٛز گژھان۔
  7. گاڑِ چھیہ ہُرِ نہٕ؟ Part B ٹیبل بٔرِو پتہٕ، تہٕ گاڑِچ فایِل e-Waybill › Update Vehicle Bulk پیٚٹھٕ اپ لوڈ کٔرِو۔

کُس وجہ باپتھ کُس ڈاکیومنٹ

وٲرِ گژھَن والیٚن سامانن باپتھ چھُ پورٹل صرف یم جوڑ قبول کران (NIC بلک جانچ):

Sub Supply Type (وجہ)Document Typeکَمس گژھان
Supply (کِنُن)INV ٹیکس انوائس، BIL بِل آف سپلائیخریدار (GSTIN والۍ یا غیر رجسٹرڈ)
Export (برآمد)INV, BILغیر رجسٹرڈ (URP)، بھارتہٕ برونہہ
Job Work (جاب ورک)CHL ڈیلیوری چالانجاب ورکر
SKD/CKD/LotsINV, BIL, CHLخریدار
For Own Use, Exhibition or Fairs, Line Sales (پانُن استعمال، نمائش/میلہ، لائن سیلز)CHLتوہۍ پانے (تُہٕنز پانُن GSTIN)
Recipient Not Known (وصول کرن والُس نہٕ پتہ)CHL, OTHتوہۍ پانے
Others (کیاہ چھُ لیکھِو)CHL, OTHتوہۍ پانے یا کُنہِ بیُن فریق

بِل آف سپلائی، ڈیلیوری چالان یا "others" منٛز چھُ ہر آئٹمُک ٹیکس ریٹ 0 گژھن۔ "own use"، نمائش، لائن سیلز تہٕ "recipient not known" منٛز چھُ میکر وصول کرن والِس جایہ تُہٕنز پانُن GSTIN پانے تھاوان۔

Transport Doc No, DateLR، RR یا ایئر وے بِل۔ ریل تہٕ ہوٲے راستس باپتھ ضروری۔

اکھ مثال

لدھیانچ اکھ گارمنٹ یونٹ چھیہ ₹38,000 ہند کٹ کرنہٕ آمت کپڑ چالان DC/26-27/045 سٕتۍ پانی پتس (ہریانہ) منٛز جاب ورکرس تام روانہ کران۔ بییس ریاستس منٛز جاب ورکس چھُ کُنہِ تہِ مالیتس ای-وے بِل ضروری۔ قطار: Document No DC/26-27/045, Document Type CHL, Sub Supply Type Job Work, GST % 0, Transport Mode Road, Vehicle No PB10AB1234, Distance 0۔

پؠٹھمس اکھ لۆکُٹ فایِل آزماوِو۔ اگر پورٹل کُنہِ قطار ردّ کرِ، تیلہِ چھُ سۄ فیلڈُک ناو ؤنان: Excel منٛز ٹھیک کٔرِو تہٕ فایِل دوبارہ بناوِو۔
